Приветствуем вас на главной странице документации Deckhouse Platform Certified Security Edition — первой платформы контейнеризации, сертифицированной ФСТЭК России.

Документация включает следующие разделы:

- [Руководство по обновлению](update.html) — описание процесса обновления DKP CSE.
- [Руководство администратора](admin-guide.html) — установка, настройка и эксплуатация платформы, управление кластером, хранилищами, сетью, безопасностью и виртуализацией.
- [Руководство пользователя](user-guide.html) — работа с платформой для пользователей: развёртывание приложений, управление ресурсами и повседневные операции.
- [Справочную информацию](reference/api/global.html) — описание глобального API, список настраиваемых параметров ОС узлов, описание сетевого взаимодействия и другие справочные материалы.
- [Справку по Deckhouse CLI](cli/d8/) — общее описание CLI-утилиты `d8` (Deckhouse CLI) и справка по доступным командам.
- [FAQ](faq.html) — ответы на часто задаваемые вопросы по работе с платформой.

Документация по модулям Deckhouse Kubernetes Platform Certified Security Edition доступна в разделе [Модули](modules/).
