### Права учётной записи

Модуль полностью работает в пользовательском API Basis Dynamix (`/restmachine/cloudapi/*`). Учётная запись с административными правами (`/restmachine/cloudbroker/*`) **не требуется** и не должна использоваться: она расширяет область видимости за пределы аккаунта владельца кластера и нарушает изоляцию.

Учётной записи, указанной в `DynamixClusterConfiguration.provider`, должны быть доступны следующие группы пользовательского API:

| Группа | Кто использует | Зачем |
| --- | --- | --- |
| `account`, `locations`, `rg` | все компоненты | получение аккаунта, локации и группы ресурсов по имени |
| `extnet`, `vins` | terraform, CAPD | внешние и внутренние сети |
| `image` | terraform, CAPD | образы ОС для узлов |
| `sep` | terraform, CSI, cloud-data-discoverer | получение доступных аккаунту storage endpoints и пулов |
| `disks` | terraform, CSI | диски master-узлов и persistent volumes |
| `compute`, `kvmx86` | terraform, CCM, CAPD, CSI | виртуальные машины и подключение дисков |
| `lb` | CCM | балансировщики для сервисов типа `LoadBalancer` |

{% alert level="warning" %}
Модулю требуется версия Basis Dynamix, в которой доступен эндпоинт `/restmachine/cloudapi/sep/listAvailableSepAndPools`. Через него определяются storage endpoints и пулы; на более старых версиях платформы StorageClass'ы не будут созданы, а master-узел не получит etcd-диск.
{% endalert %}

### Подготовка образа операционной системы

Вендоры операционных систем предоставляют специальные образы ОС (сборки), подготовленные для работы в облачной среде. Эти образы, как правило, содержат драйверы для виртуального оборудования, пакет `cloud-init`, гостевые агенты систем виртуализации и распространяются в виде образов дисков в форматах IMG или QCOW2. Мы рекомендуем использовать именно такие образы в качестве ОС на узлах ваших кластеров.

Образ операционной системы должен быть размещен в разделе «Образы» → «Шаблонные образы» на портале Basis Dynamix.

В случае, если в инфраструктуре отсутствует DNS-сервер, доступ к порталу Basis Dynamix из кластера можно организовать добавлением IP-адреса и доменов, связанных с порталом Basis Dynamix, в шаблон `cloud-init` для генерации файла hosts.
Данный шаблон расположен в папке `/etc/cloud/templates/`. Название шаблона зависит от ОС.

{% alert level="warning" %}
Провайдер поддерживает работу только с одним диском в шаблоне виртуальной машины. Убедитесь, что шаблон содержит только один диск.
{% endalert %}

{% alert level="warning" %}
После добавления данных в файл `hosts` и перед созданием шаблона из виртуальной машины, выполните команду `cloud-init clean`.
{% endalert %}
