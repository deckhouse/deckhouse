---
title: "Cloud provider — VMware vSphere: настройки провайдера"
description: Настройки облачного провайдера Deckhouse для VMware vSphere.
---

> Ресурс VsphereClusterConfiguration описывает конфигурацию облачного кластера и применяется, если control plane кластера размещён в облаке.
>
> Если control plane работает на виртуальных машинах или серверах bare metal, провайдер берёт настройки из [конфигурации модуля](configuration.html). Балансировка входящего трафика описана в разделе [«Балансировка нагрузки»](environment.html#балансировка-нагрузки).
