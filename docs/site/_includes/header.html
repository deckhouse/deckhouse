{%- comment -%} The header for the English pages is islandKit. The markup inside the mount point is rendered by the same Vue component that runs in the browser: it is generated during the build phase (_tools/islandkit/render-header.mjs). Russian pages do not appear here: layouts are selected based on the language header_ru.html. Two types of fragments: - website — based on a fragment for each product and language. A product for which no fragment has been generated receives the default product header; otherwise, `include` causes the entire build to fail because of a single page; - build within a cluster (site.mode == module) — one fragment per language with its own documentation module menu. It is rendered by the same stage in module mode (docs/site/werf-islandkit.inc.yaml) for this build. {%- endcomment -%} {%- if site.mode == "module" -%} {%- assign ikFragment = "_generated/header-module-en.html" -%} {%- else -%} {%- assign ikProduct = page.product_code | default: "kubernetes-platform" -%} {%- unless site.data.islandkit_header.products contains ikProduct -%} {%- assign ikProduct = "kubernetes-platform" -%} {%- endunless -%} {%- assign ikFragment = "_generated/header-" | append: ikProduct | append: "-en.html" -%} {%- endif -%}
