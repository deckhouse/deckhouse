{%- comment -%} The header for the Russian pages uses the same islandKit as the English pages, but in the second design. The markup is generated during the build phase (_tools/islandkit/render-header.mjs); the design is defined by variables in _sass/components/_islandkit-header.scss within the .header--ik-ru class, rather than custom markup. There are two types of fragments: - website — one fragment per product. Product codes that the Russian header displays under different names (kubernetes-platform, development-platform) are resolved by the build phase: the fragment for each code already contains the correct branch. Here, only the fragment selection and the default product are specified; - Intra-cluster build (site.mode == module) — a single fragment with its own documentation module menu, specific to this build. {%- endcomment -%} {%- if site.mode == "module" -%} {%- assign ikFragment = "_generated/header-module-ru.html" -%} {%- else -%} {%- assign ikProduct = page.product_code | default: "deckhouse-platform" -%} {%- unless site.data.islandkit_header.products contains ikProduct -%} {%- assign ikProduct = "deckhouse-platform" -%} {%- endunless -%} {%- assign ikFragment = "_generated/header-" | append: ikProduct | append: "-ru.html" -%} {%- endif -%}
