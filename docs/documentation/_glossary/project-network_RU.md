---
title: Сеть проекта
description: Дополнительная программно-определяемая сеть, доступная в пределах одного неймспейса. Пользователь создаёт её и управляет ею на основе [NetworkClass](/modules/sdn/cr.html#networkclass), предоставленного администратором. Другое название — пользовательская сеть.
lang: ru
---

Администратор задаёт в NetworkClass диапазон VLAN-тегов и сетевые интерфейсы узлов, на основе которых пользователи могут создавать собственные сети. Пользователь создаёт сеть с помощью объекта Network в [неймспейсе](glossary.html#namespace) [проекта](glossary.html#project). Пользователи могут выделить для сети проекта пул адресов и назначать адреса интерфейсам подов через [IPAM](glossary.html#sdn-ipam). Второй вид [дополнительной сети](glossary.html#additional-network) — [кластерная сеть](glossary.html#cluster-network).

Подробнее в разделе [«Дополнительные сети для использования в прикладных подах»](user/network/sdn/dedicated.html).
