---
title: Дополнительный неймспейс проекта
description: Пользовательский неймспейс, который создаётся в рамках проекта в дополнение к основному. Используется только для запуска полезной нагрузки.
lang: ru
---

Дополнительные неймспейсы позволяют логически разделить полезную нагрузку внутри [проекта](glossary.html#project) и применять к её частям отдельные политики доступа. Как и [основной неймспейс проекта](glossary.html#main-project-namespace), дополнительный неймспейс проекта является [пользовательским неймспейсом](glossary.html#user-namespace).
