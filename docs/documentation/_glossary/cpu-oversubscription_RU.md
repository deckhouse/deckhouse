---
title: Переподписка CPU
description: Выдача виртуальным машинам узла большего числа виртуальных ядер, чем на нём есть физических. Степень переподписки определяется долей ядра, гарантированной виртуальной машине.
lang: ru
---

Параметр `coreFraction` виртуальной машины определяет долю мощности ядра, которая ей гарантирована. Допустимые значения задаются в [политике сайзинга](glossary.html#sizing-policy) класса. При `coreFraction: 20%` машина всегда получает пятую часть ядра, а при наличии свободных ресурсов на узле может занять ядро целиком. При размещении машины Deckhouse Platform суммирует гарантированные доли всех машин узла, и если сумма превышает число физических ядер, машина на этом узле не запускается.

Подробнее в разделе [«Переподписка на CPU для виртуальных машин»](admin/configuration/virtualization/cpu-oversubscription.html).
