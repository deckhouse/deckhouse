---
title: Additional project namespace
description: A user namespace created within a project in addition to the main one. It is used only to run the workload.
lang: en
---

Additional namespaces let you divide the workload of a [project](glossary.html#project) logically and apply separate access policies to each part. Like the [main project namespace](glossary.html#main-project-namespace), an additional project namespace is a [user namespace](glossary.html#user-namespace).
