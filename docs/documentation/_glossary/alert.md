---
title: Alert
description: A notification of the Deckhouse Platform monitoring system about an event in the cluster or its components.
lang: en
---

The standard delivery includes a set of basic alerts that cover the state of the cluster and its components. Custom alerts can be added. Alerts are sent to external systems through Alertmanager: by SMTP, to PagerDuty, Slack, Telegram or by webhook.

The list of all alerts of the monitoring system is given in the [Alerts](reference/alerts.html) reference.
