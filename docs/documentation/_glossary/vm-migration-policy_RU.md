---
title: Политика миграции ВМ
description: Политика, которая определяет, когда живая миграция виртуальной машины использует механизм AutoConverge, то есть замедление процессора для гарантированного завершения миграции. Задаётся параметром liveMigrationPolicy машины.
lang: ru
---

AutoConverge постепенно снижает частоту процессора исходной машины, чтобы появлялось меньше изменённых страниц памяти, и завершает [живую миграцию](glossary.html#live-migration), как только скорость передачи превысит скорость изменения памяти. Он помогает при медленной сети ценой производительности приложений в машине.

Допустимые значения: `AlwaysSafe` (никогда не замедлять), `PreferSafe` (по умолчанию, без замедления, но миграция с `force=true` может замедлять), `AlwaysForced` (всегда использовать AutoConverge) и `PreferForced` (использовать AutoConverge, но миграция с `force=false` выполняется без него).

Подробнее в разделе [«Живая миграция виртуальных машин»](user/virtualization/vm-migration.html).
