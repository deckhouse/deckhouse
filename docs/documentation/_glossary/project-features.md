---
title: Project features
description: The set of platform capabilities available within a project. Features define which APIs and resource kinds can be used in the project.
lang: en
---

Project features are not a part of the [role model](glossary.html#rbac). Examples of features: Kubernetes, Virtualization. The features of a single namespace within the project are limited by the [project namespace features](glossary.html#project-namespace-features).
