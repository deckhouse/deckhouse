title: Топология CPU виртуальной машины
description: Распределение ядер процессора виртуальной машины по сокетам. Пользователь задаёт только общее число ядер, а число сокетов рассчитывает Deckhouse Platform.
lang: ru
---

Чем больше ядер, тем на большее число сокетов они делятся и тем крупнее шаг, с которым можно менять их количество: до 16 ядер используют один сокет, до 32 — два, до 64 — четыре, до 248 — восемь. Общее число ядер должно быть кратно числу сокетов. Топология важна для приложений, чувствительных к конфигурации процессора.

Число ядер работающей машины в пределах текущей топологии меняется [живой миграцией](glossary.html#live-migration), если включена соответствующая возможность. Изменение, требующее смены топологии, требует перезагрузки.

Подробнее в разделе [«Процессор и память виртуальной машины»](user/virtualization/vm-resources.html).
