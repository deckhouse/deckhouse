lang: ru

Политика состоит из списка правил, каждое из которых относится к своему диапазону ядер. Диапазоны не должны пересекаться. Изменения политики затрагивают уже существующие виртуальные машины: у машины, которая перестала соответствовать требованиям, условие `SizingPolicyMatched` принимает статус `False`. Допустимые значения доли ядра, заданные в политике, определяют степень [переподписки CPU](glossary.html#cpu-oversubscription).

Подробнее в разделе [«Политика сайзинга виртуальных машин»](admin/configuration/virtualization/vm-classes-sizing.html).
