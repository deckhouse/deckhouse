---
title: Conformance-тесты Kubernetes
description: Проверка Deckhouse Platform набором conformance-тестов программы CNCF Certified Kubernetes Conformance Program. Тесты выполняются для каждой поддерживаемой минорной версии Kubernetes.
lang: ru
---

Тесты запускаются с помощью Sonobuoy в режиме `certified-conformance`, отчёты JUnit публикуются в справке. Результаты актуальны только при выключенном модуле [`multitenancy-manager`](/modules/multitenancy-manager/).

Подробнее в разделе [«Результаты conformance-тестов Kubernetes»](reference/kubernetes-conformance.html).
