title: Облачный провайдер
description: Облачная платформа или система виртуализации, с которой Deckhouse Platform интегрирован через модуль cloud-provider-*, чтобы создавать виртуальные машины, подключать их к кластеру как узлы и создавать базовые ресурсы инфраструктуры.
lang: ru
---

Порядок работы одинаков для всех провайдеров, различаются только подготовительные шаги, например создание сервисного аккаунта, и файлы конфигурации. Интеграция позволяет использовать [узлы CloudEphemeral](glossary.html#cloud-ephemeral-node), которые Deckhouse Platform создаёт и удаляет через API провайдера, и выбирать [схему размещения](glossary.html#layout).

Подробнее в разделе [«Интеграция с IaaS»](admin/integrations/integrations-overview.html).
