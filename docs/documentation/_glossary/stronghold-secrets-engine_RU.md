Механизмами секретов управляют в веб-интерфейсе Stronghold: для каждого механизма показаны список секретов (роли, ключи и другие), его конфигурация и кнопка добавления нового секрета. Веб-интерфейс предоставляет модуль [`stronghold`](/modules/stronghold/), он открывается по адресу `stronghold.<CLUSTER_NAME_TEMPLATE>`.

Подробнее в разделе [«Веб-интерфейс управления секретами»](user/web/stronghold.html).
