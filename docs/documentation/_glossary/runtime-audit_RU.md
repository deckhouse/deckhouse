title: Рантайм-аудит
description: Поиск угроз безопасности в работающем кластере за счёт анализа событий ядра Linux и событий аудита API Kubernetes.
lang: ru
---

Рантайм-аудит в Deckhouse Platform использует два источника событий: события ядра Linux, получаемые через eBPF-драйвер системы обнаружения угроз Falco, и события [аудита API Kubernetes](glossary.html#kubernetes-api-audit), получаемые через вебхук. Он выявляет попытки применения известных уязвимостей, признаки криптовалютных майнеров и угрозы Kubernetes: оболочки командной строки в контейнерах, привилегированные контейнеры, монтирование небезопасных путей и чтение секретных файлов.

Для перехвата событий ядра требуется ядро Linux версии 5.8 или новее с поддержкой eBPF.

Подробнее в разделе [«Рантайм-аудит»](admin/configuration/security/events/runtime-audit.html).
