---
title: Федерация
description: Модель межкластерного взаимодействия, которая объединяет независимые кластеры. У каждого кластера собственные неймспейсы и сервисы, а доступ между кластерами настраивается явно.
lang: ru
---

В федерации администратор указывает, какие сервисы доступны извне кластера. Модель реализуется средствами Istio через модуль [`istio`](/modules/istio/) и строится на [сервис-меше](glossary.html#service-mesh). Модель для тесно связанных кластеров — [мультикластер](glossary.html#multicluster).

Подробнее в разделе [«Межкластерное взаимодействие»](admin/configuration/network/alliance/).
