---
title: Программно-определяемая сеть (SDN)
description: Дополнительный сетевой сегмент для подов и виртуальных машин, который администратор описывает декларативно в кастомных ресурсах, а модуль [`sdn`](/modules/sdn/) настраивает на узлах.
lang: ru
---

Программно-определяемые сети в Deckhouse Platform охватывают настройку сетевых интерфейсов на узлах (агрегацию портов, мосты, VLAN-интерфейсы), дополнительные сети для нагрузки, доступные во всём кластере или в пределах одного неймспейса (сети проекта), управление IP-адресами этих сетей, underlay-сети для проброса физических интерфейсов приложениям и системные сети для служебного трафика на уровне узла.

Подробнее в разделе [«Программно-определяемые сети»](admin/configuration/network/sdn/).
