---
title: Критичный модуль
description: Модуль с параметром critical, равным true, в module.yaml. Он запускается при начальной инициализации кластера, до того как кластер считается полностью готовым. Остальные модули запускаются только после этого.
lang: ru
---

[Контроллер Deckhouse](glossary.html#deckhouse-controller) помещает задачи критичных модулей в [очередь](glossary.html#addon-operator-queue) `main` по возрастанию [веса модуля](glossary.html#module-weight). Некритичные модули обрабатываются в параллельных очередях без учёта веса. Если критичные модули можно обработать параллельно, контроллер запускает их пакетом и ждёт завершения, прежде чем продолжить очередь `main`.

Подробнее в разделе [«Механизм очередей»](architecture/deckhouse/queues.html).
