---
title: Deckhouse web UI
description: The web interface of Deckhouse Platform for cluster management, including monitoring, parameter configuration, node and module management, security and network configuration.
lang: en
---

Most operations available from the command line through [Deckhouse CLI](glossary.html#deckhouse-cli) or `kubectl` can also be performed in the web UI. It opens at `console.<CLUSTER_NAME_TEMPLATE>`, where the template is the [DNS name template](glossary.html#public-domain-template) of the cluster, and contains the sections Deckhouse, node management, multitenancy, access, network, storage, security, monitoring and logging.

For details, see [Deckhouse Platform web UI](user/web/ui.html).
