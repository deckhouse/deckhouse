Образ описывает [VirtualImage](/modules/virtualization/cr.html#virtualimage). Его источником может быть HTTP-сервер с файлом образа, хранилище образов контейнеров, файл, загруженный из командной строки, другой образ, [диск виртуальной машины](glossary.html#vm-disk) или [снимок диска](glossary.html#vm-snapshot). Загруженный образ хранится либо в [DVCR](glossary.html#dvcr), либо в PVC. Образ в PVC годится для создания дисков только в том же классе хранения.

Чтобы образ был доступен всем [проектам](glossary.html#project) кластера, администратор создаёт кластерный образ [ClusterVirtualImage](/modules/virtualization/cr.html#clustervirtualimage). К [виртуальной машине](glossary.html#virtual-machine) образы подключаются как [блочные устройства](glossary.html#vm-block-device): только для чтения или как CD-ROM для ISO-образов.

Подробнее в разделе [«Образы виртуальных машин»](user/virtualization/images.html).
