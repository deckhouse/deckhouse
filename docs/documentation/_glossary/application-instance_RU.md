lang: ru

Каждый экземпляр полностью независим: два экземпляра Redis, для кеширования и для сессий, могут работать в одном [неймспейсе](glossary.html#namespace). Deckhouse Platform обрабатывает каждый экземпляр в отдельной очереди. Объекты экземпляра называются `d8a-<INSTANCE_NAME>-<SUFFIX>`, поэтому имя экземпляра не длиннее 24 символов, а каждый отрендеренный объект получает лейбл `packages.deckhouse.io/instance`.

Подробнее в разделе [«Установка и управление приложениями»](user/marketplace/applications.html).
