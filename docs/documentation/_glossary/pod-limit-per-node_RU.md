---
title: Лимит подов на узел
description: Максимальное количество подов, которые могут быть размещены на узле. В Deckhouse Platform он вычисляется из размера подсети узла, задаваемого параметром podSubnetNodeCIDRPrefix при развёртывании кластера.
lang: ru
---

При префиксе 24 и больше узел вмещает 120 подов, при 23 — 250, при 22 — 500, при 21 и меньше — 1000. Параметр относится к [защищённым параметрам](glossary.html#protected-parameters) кластера, поэтому выбирайте значение при развёртывании, если на узлах ожидается много подов. Компоненты control plane для высокой плотности подов Deckhouse Platform настраивает автоматически.

Подробнее в разделе [«Высокая плотность подов»](guides/high-pod-density.html).
