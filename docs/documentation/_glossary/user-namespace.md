---
title: User namespace
description: A namespace in which the workload runs. It always belongs to one project.
lang: en
---

A user namespace always belongs to one [project](glossary.html#project) and cannot have the prefix of a [system namespace](glossary.html#system-namespace).

The namespaces of a project are divided into the [main project namespace](glossary.html#main-project-namespace) and [additional project namespaces](glossary.html#additional-project-namespace).
