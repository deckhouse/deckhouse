Пул описывает [VirtualMachinePool](/modules/virtualization/cr.html#virtualmachinepool). Его шаблон совпадает с обычной спецификацией виртуальной машины, поэтому реплика ничем не отличается от вручную созданной [виртуальной машины](glossary.html#virtual-machine). Диски реплик описываются один раз в шаблонах дисков с [политикой reclaim](glossary.html#vm-pool-reclaim-policy), размером и источником данных, а шаблон ссылается на них в порядке загрузки. Общие [образы](glossary.html#vm-image), например единый ISO для всех реплик, подключаются только для чтения.

Реплики различаются [начальной инициализацией](glossary.html#vm-provisioning), поэтому тип ОС `Legacy` в пуле не поддерживается.

Подробнее в разделе [«Пулы виртуальных машин»](user/virtualization/vm-pools.html).
