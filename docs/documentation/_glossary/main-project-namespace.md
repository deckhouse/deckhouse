---
title: Main project namespace
description: The user namespace that is created together with the project. It is used to manage additional project namespaces and to run the workload.
lang: en
---

The main project namespace is a [user namespace](glossary.html#user-namespace) created as part of a [project](glossary.html#project). [Additional project namespaces](glossary.html#additional-project-namespace) are managed from it.
