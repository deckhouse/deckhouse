---
title: Ресурс кластера, доступный проекту
description: Cluster-wide-ресурс, например StorageClass, который модуль [`multitenancy-manager`](/modules/multitenancy-manager/) делает доступным проекту по гранту. Настройки приложения, связанные с таким ресурсом, получают значение по умолчанию проекта и проверяются по списку доступных проекту ресурсов.
lang: ru
---

Поле `settings` типа `string` связывается с доступным по гранту ресурсом расширением `x-deckhouse-grantable-resource`, в котором указано имя ресурса, доступного [проекту](glossary.html#project), например `storageclasses`. Если пользователь оставил поле пустым, в values подставляется имя ресурса, заданное как значение по умолчанию проекта. Значение, которого нет в списке доступных проекту ресурсов, отклоняется. Группа, версия и вид ресурса определяются грантом.

Подробнее в разделе [«Настройки приложения»](architecture/marketplace/settings.html).
