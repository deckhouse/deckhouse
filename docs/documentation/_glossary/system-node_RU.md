---
title: Системный узел
description: Узел, выделенный для запуска модулей Deckhouse Platform, чтобы они не пересекались с пользовательскими приложениями.
lang: ru
---

Системные узлы изолируются лейблами и taints, чтобы на них не планировались пользовательские поды. Рекомендуется выделить два системных узла. Системные узлы могут быть [статическими](glossary.html#static-node) или облачными и обычно образуют [группу узлов](glossary.html#node-group) `system`. Если в кластере нет выделенных [узлов мониторинга](glossary.html#monitoring-node), компоненты мониторинга тоже работают на системных узлах.

Подробнее в разделе [«Рекомендации по настройке узлов кластера»](admin/configuration/high-reliability-and-availability/recommendations.html).
