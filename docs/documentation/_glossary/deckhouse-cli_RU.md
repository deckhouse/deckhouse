lang: ru

Начиная с релиза 1.59, `d8` устанавливается на все узлы кластера Deckhouse Platform. Его также можно установить через [trdl](https://trdl.dev/) (open-source инструмент безопасной доставки и обновления бинарных файлов) или из исполняемого файла. Команды сгруппированы по назначению: `d8 k` эквивалентна `kubectl`, `d8 system` работает с настройками платформы, модулями, очередями и пакетами, `d8 mirror` копирует образы платформы, `d8 v` управляет виртуальными машинами, `d8 backup` создаёт резервные копии.

Подробнее в разделе [«Обзор и установка Deckhouse CLI»](cli/d8/).
