---
title: Политика обновления модуля
description: Правила, по которым Deckhouse Platform обновляет модуль из источника в кластере. Задаётся с помощью объекта [ModuleUpdatePolicy](reference/api/cr.html#moduleupdatepolicy) и определяет режим обновления, канал обновлений и окна обновлений модуля.
lang: ru
---

Политика задаёт [режим обновления](glossary.html#update-mode) (автоматический, ручной или обновления отключены), [канал обновлений](glossary.html#release-channel), используемый при обновлении, и [окна обновлений](glossary.html#update-window), в пределах которых разрешено автоматическое обновление. Если политика для модуля не определена, модуль обновляется по настройкам платформы из параметра `update` модуля [`deckhouse`](/modules/deckhouse/). Релиз модуля в статусе `Pending` ждёт ручного подтверждения.

Подробнее в разделе [«Как запустить и проверить модуль в кластере DP»](architecture/module-development/run/).
