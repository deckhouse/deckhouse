---
title: Кеширующий DNS-сервер
description: DNS-сервер, который модуль [`node-local-dns`](/modules/node-local-dns/) запускает на каждом узле кластера. Он кеширует ответы DNS и убирает сетевой обмен с кластерным DNS для повторяющихся запросов.
lang: ru
---

На каждом узле модуль настраивает интерфейс с IP-адресом сервиса [`kube-dns`](/modules/kube-dns/), запускает на этом адресе кеширующий CoreDNS и добавляет правило iptables, которое перенаправляет DNS-трафик на него, пока открыт его сокет. Иначе используется стандартная маршрутизация через кластерный DNS. Внешние запросы, которых ещё нет в кеше, по-прежнему сначала разрешаются через цепочку внутренних зон, но под нагрузкой одного кеширования достаточно, чтобы заметно ускорить разрешение имён.

Подробнее в разделе [«Кеширующий DNS-сервер в кластере»](architecture/network/dns-caching.html).
