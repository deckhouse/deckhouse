---
title: HA mode
description: A mode in which critical Deckhouse Platform components run with redundancy, so that the failure of a single instance does not stop the service.
lang: en
---

HA mode is enabled automatically when the cluster has more than one [master node](glossary.html#master-node), both at the initial deployment and when nodes are added later. It can also be managed manually.

For details, see [High reliability and availability](admin/configuration/high-reliability-and-availability/).
