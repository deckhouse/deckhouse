---
title: Долговременное хранилище метрик
description: Отдельное хранилище, например VictoriaMetrics, в которое Prometheus отправляет метрики с помощью механизма remote_write.
lang: ru
---

В Deckhouse Platform отправка метрик в долговременное хранилище настраивается с помощью объекта [PrometheusRemoteWrite](/modules/prometheus/cr.html#prometheusremotewrite).

Подробнее в разделе [«Запись данных Prometheus в долговременное хранилище»](admin/configuration/monitoring/configuring/longterm-storage.html).
