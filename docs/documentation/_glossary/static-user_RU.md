---
title: Статический пользователь
description: Пользователь, созданный в кластере как объект User локальной аутентификации, с email и хешем пароля, без внешнего провайдера аутентификации.
lang: ru
---

Статические пользователи и группы лежат в основе локальной аутентификации в Deckhouse Platform. Объект User хранит данные пользователя и хеш пароля, сам пароль в открытом виде не хранится. Объект Group задаёт список пользователей. Локальная аутентификация поддерживает парольные политики и временных пользователей с TTL. Доступна также двухфакторная аутентификация.

Рекомендуемый способ создать статического пользователя — команда `d8 iam user create`.

Подробнее в разделе [«Локальная аутентификация»](admin/configuration/access/authentication/local.html).
