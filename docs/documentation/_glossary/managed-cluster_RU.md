Модуль [`commander-agent`](/modules/commander-agent/) подключает кластер к модулю [`commander`](/modules/commander/) [управляющего кластера](glossary.html#managing-cluster). Не путайте с Managed Kubernetes-кластером, в котором control plane предоставляет облачный провайдер: см. [кластер под управлением Deckhouse Platform](glossary.html#dp-managed-cluster).

Подробнее в разделе [«Управление кластерами»](architecture/deckhouse/commander.html).
