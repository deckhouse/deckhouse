---
title: Начальная инициализация ВМ
description: Первичная настройка гостевой системы виртуальной машины при первом запуске сценарием инициализации, Cloud-Init для Linux или Sysprep для Windows.
lang: ru
---

Сценарий инициализации создаёт пользователей, задаёт пароли и SSH-ключи, устанавливает программы, выполняет команды и включает службы, например [агент гостевой ОС](glossary.html#vm-guest-agent). Конфигурация Cloud-Init записывается в формате YAML и начинается с заголовка `#cloud-config`.

Реплики [пула виртуальных машин](glossary.html#vm-pool) различаются начальной инициализацией, поэтому операционные системы без неё, тип ОС `Legacy`, в пулах не поддерживаются.

Подробнее в разделе [«Начальная инициализация и агент гостевой ОС»](user/virtualization/vm-provisioning.html).
