lang: ru
---

Deckhouse Platform собирает события безопасности из контейнерных источников, то есть логов приложений в подах, и из кластерных источников, например журнала [аудита API Kubernetes](glossary.html#kubernetes-api-audit) и логов аутентификации на узлах. Модуль [`log-shipper`](/modules/log-shipper/) выполняет предварительный отбор записей, а модуль [`security-events-manager`](/modules/security-events-manager/) разбирает их, приводит к единому формату с обязательным набором атрибутов, обогащает контекстом и доставляет в системы хранения и аналитики, например Loki, Elasticsearch, Kafka или Splunk.

Подробнее в разделе [«События безопасности»](admin/configuration/security/events/security-events.html).
