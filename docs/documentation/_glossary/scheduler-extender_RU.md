lang: ru

Модуль [`sds-local-volume`](/modules/sds-local-volume/) размещает поды с локальными томами с учётом свободного места на узлах и места, которое нужно зарезервировать под тома. Его вебхук задаёт таким подам `spec.schedulerName` со значением `sds-local-volume`. Модуль [`csi-nfs`](/modules/csi-nfs/) размещает поды по селекторам узлов из NFSStorageClass, а модуль [`sdn`](/modules/sdn/) предлагает узлы в соответствии с настройками сетевых интерфейсов подов, использующих [программно-определяемые сети](glossary.html#sdn). kube-scheduler отправляет запросы на планирование таких подов на вебхук расширения.

Подробнее в разделе [«Архитектура хранилищ»](architecture/storage/).
