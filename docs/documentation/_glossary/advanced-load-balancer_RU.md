Расширенный балансировщик реализован на объектах [ServiceWithHealthchecks](/modules/service-with-healthchecks/cr.html#servicewithhealthchecks). Он состоит из контроллера, который работает на [master-узлах](glossary.html#master-node) и управляет этими объектами, и агентов на каждом узле, которые выполняют пробы и публикуют только проверенные адреса. Стандартный балансировщик, сервис Kubernetes, остаётся доступен для нагрузок, которым отдельные пробы не нужны.

Подробнее в разделе [«Внутрикластерное взаимодействие»](user/network/intra-cluster.html).
