---
title: Alert severity
description: The Severity (S) parameter of an alert that indicates its level of criticality, from S1 for a critical failure that requires immediate action to S4–S9 for a low-level problem that does not impair overall performance.
lang: en
---

Every [alert](glossary.html#alert) description contains the Severity parameter with a value from `S1` to `S9`:

- `S1` is the maximum level, a critical failure that requires immediate action;
- `S2` is a high level close to the maximum, a possible accident that requires rapid response;
- `S3` is a medium level, a potentially serious problem that requires verification;
- `S4` to `S9` are low levels, a problem that does not impair overall performance.

The severity of every alert is shown in the [list of alerts](reference/alerts.html).
