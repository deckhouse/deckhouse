lang: ru

Node-agent — опциональный компонент, который работает на всех узлах кластера в привилегированном режиме, наблюдает за поведением контейнеров с помощью eBPF-программ и сохраняет профили в объектах ApplicationProfile и NetworkNeighborhood. Он работает в режиме профилирования и не выявляет атаки по правилам. Это задача [рантайм-аудита](glossary.html#runtime-audit). На основе профилей можно генерировать сетевые политики по наблюдаемому трафику.

Подробнее в разделе [«Модуль operator-trivy»](architecture/security/operator-trivy.html).
