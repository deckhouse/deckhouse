title: Patch version
description: A Deckhouse Platform release that includes fixes. Patch versions are published when needed.
lang: en
---

A patch version is one of the two types of a [Deckhouse Platform release](glossary.html#dp-release), the other being a [minor version](glossary.html#minor-version). In the `AutoPatch` [update mode](glossary.html#update-mode) only patch versions are installed automatically. Starting from Deckhouse Platform 1.70 they are applied with [update windows](glossary.html#update-window) taken into account.

For details, see [Updating](architecture/updating.html).
