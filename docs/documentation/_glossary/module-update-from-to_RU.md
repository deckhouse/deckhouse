---
title: Пропуск промежуточных релизов модуля
description: Механизм from-to, который позволяет Deckhouse Platform пропускать пошаговые обновления модуля. Если установленная версия модуля попадает в диапазон from-to из module.yaml, Deckhouse Platform устанавливает последнюю версию в пределах to.
lang: ru
---

Правила перехода перечисляются в секции `update.versions` файла `module.yaml`. Релиз, который их содержит, называется релизом с ограничениями. Правило читается из релиза, на который выполняется переход, и его `to` должно совпадать с версией этого релиза. Если установленная версия ниже `from`, обновление идёт последовательно. Если подходят несколько правил, выбирается правило с наибольшим `to`.

Подробнее в разделе [«Разработка и отладка модуля»](architecture/module-development/development/).
