---
title: Вес модуля
description: Число из параметра weight файла module.yaml, которое определяет порядок запуска модулей. Модули с меньшим весом запускаются раньше, по умолчанию вес равен 900.
lang: ru
---

Если файла `module.yaml` нет, вес берётся из числового префикса директории модуля, например `040-node-manager` означает вес 40. Если получить его не удалось, используется 100. [Контроллер Deckhouse](glossary.html#deckhouse-controller) учитывает вес только для [критичных модулей](glossary.html#critical-module), задачи которых попадают в очередь `main` по возрастанию веса. На порядок запуска также влияют [зависимости модуля](glossary.html#module-dependencies).

Подробнее в разделе [«Механизм очередей»](architecture/deckhouse/queues.html).
