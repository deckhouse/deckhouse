---
title: Long-term metrics storage
description: A separate storage, for example VictoriaMetrics, to which Prometheus sends metrics with the remote_write mechanism.
lang: en
---

In Deckhouse Platform, sending metrics to a long-term storage is configured with a [PrometheusRemoteWrite](/modules/prometheus/cr.html#prometheusremotewrite) object.

For details, see [Writing Prometheus data to longterm storage](admin/configuration/monitoring/configuring/longterm-storage.html).
