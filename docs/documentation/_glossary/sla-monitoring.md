---
title: SLA monitoring
description: Collection of availability statistics of cluster components and Deckhouse Platform components by the upmeter module to evaluate SLA compliance.
lang: en
---

Availability data is shown in the web interface and can be exported over the Prometheus Remote Write protocol with an [UpmeterRemoteWrite](/modules/upmeter/cr.html#upmeterremotewrite) object.

For details, see [Cluster SLA monitoring](admin/configuration/monitoring/sla.html).
