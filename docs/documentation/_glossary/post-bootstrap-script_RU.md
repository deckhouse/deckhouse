---
title: Post-bootstrap-скрипт
description: Пользовательский скрипт, который установщик выполняет на одном из master-узлов после завершения установки кластера.
lang: ru
---

Скрипт используется для дополнительной настройки кластера, сбора диагностической информации или интеграции с внешними системами. Путь к нему передаётся [установщику](glossary.html#installer) параметром `--post-bootstrap-script-path`.

Подробнее в разделе [«Установка платформы»](installing/).
