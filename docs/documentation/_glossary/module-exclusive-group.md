---
title: Module exclusive group
description: A group of modules that share one value of the exclusiveGroup parameter in module.yaml. Only one module of the group can be active in the cluster at a time.
lang: en
---

Exclusive groups prevent conflicts between [modules](glossary.html#module) that perform similar or incompatible functions. Enabling a second module of the same group is not possible while the first one is active.

For details, see [Module structure](architecture/module-development/structure/).
