---
title: Мультикластер
description: Модель межкластерного взаимодействия, которая тесно объединяет кластеры. Кластеры используют общие неймспейсы, а сервисы одного кластера доступны другим как локальные.
lang: ru
---

Доступ к сервисам других кластеров можно ограничить политиками авторизации. Модель реализуется средствами Istio через модуль [`istio`](/modules/istio/) и строится на [сервис-меше](glossary.html#service-mesh). Модель для независимых кластеров — [федерация](glossary.html#federation).

Подробнее в разделе [«Межкластерное взаимодействие»](admin/configuration/network/alliance/).
