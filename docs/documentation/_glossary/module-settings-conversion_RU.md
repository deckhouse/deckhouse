---
title: Конверсия параметров модуля
description: Правило в директории `openapi/conversions` модуля, которое преобразует параметры модуля из одной версии OpenAPI-спецификации в следующую, например при переименовании или переносе параметра.
lang: ru
---

Каждая конверсия работает между двумя смежными версиями и хранится в файле `v<N>.yaml` вместе с тестами. Цепочка конверсий должна покрывать все версии спецификации параметров без пропусков, чтобы Deckhouse Platform автоматически преобразовывал настройки [модуля](glossary.html#module) при смене версии схемы его настроек.

Подробнее в разделе [«Структура модуля»](architecture/module-development/structure/).
