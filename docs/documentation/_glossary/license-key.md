---
title: License key
description: The credential required for using the commercial editions of Deckhouse Platform.
lang: en
---

The license key is required to pull images of the commercial [editions](glossary.html#edition) from `registry.deckhouse.io`, for example when updating a cluster in a [private environment](glossary.html#private-environment) with `d8 mirror pull`.

For details, see [Updating DP in air-gapped environment](guides/airgapped-update.html).
