---

Для экспорта нужен включённый модуль [`storage-volume-data-manager`](/modules/storage-volume-data-manager/), а в командной строке утилита `d8` версии 0.20.7 и выше. Экспорт выполняет команда `d8 data export download`. [Диск](glossary.html#vm-disk) не должен использоваться в момент экспорта, поэтому машину, к которой он подключён, сначала останавливают. Вместо диска можно выгрузить его [снимок](glossary.html#vm-snapshot).

Скачанный файл импортируют обратно в кластер, загрузив его как [образ](glossary.html#vm-image) или как диск.

Подробнее в разделе [«Экспорт данных диска виртуальной машины»](user/virtualization/data-export.html).
