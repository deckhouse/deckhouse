description: Одна из эталонных конфигураций кластера для оценки ресурсов под ожидаемую нагрузку, минимальная, типовая или с повышенной нагрузкой.
lang: ru
---

Минимальная конфигурация включает один [master-узел](glossary.html#master-node) и хотя бы один [worker-узел](glossary.html#worker-node). Она подходит для небольших проектов с невысокими требованиями к надёжности, так как отказ master-узла влияет на весь кластер. Типовая конфигурация добавляет ещё два master-узла, два [frontend-узла](glossary.html#frontend-node) и два [системных узла](glossary.html#system-node) и переживает отказ одного master-узла. Конфигурация с повышенной нагрузкой добавляет два [узла мониторинга](glossary.html#monitoring-node) для наблюдаемости под высокой нагрузкой.

Подробнее в разделе [«Требования к аппаратному обеспечению»](guides/hardware-requirements.html).
