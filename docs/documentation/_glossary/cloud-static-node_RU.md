---
title: Узел CloudStatic
description: Узел, созданный вручную или внешними инструментами в облаке, для которого настроена интеграция с провайдером, и подключённый к кластеру bootstrap-скриптом. На нём работает CSI, а объектом Node управляет cloud-controller-manager.
lang: ru
---

Объект Node узла CloudStatic автоматически получает зону и регион из данных провайдера. Если машина удалена из облака, её объект Node удаляется из кластера. Как и [статический узел](glossary.html#static-node), узел CloudStatic не поддерживает автоматическое масштабирование и обновление.

Подробнее в разделе [«Добавление и управление облачными узлами»](admin/configuration/platform-scaling/node/cloud-node.html).
