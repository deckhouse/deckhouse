Проекты обеспечивают изоляцию, поддерживают создание по шаблонам, контролируют доступные команде возможности платформы и совместимы с [неймспейсами](glossary.html#namespace) Kubernetes. Проект включает [основной неймспейс проекта](glossary.html#main-project-namespace) и может включать [дополнительные неймспейсы проекта](glossary.html#additional-project-namespace).

Подробнее в разделе [«Мультитенантность»](admin/multitenancy.html).
