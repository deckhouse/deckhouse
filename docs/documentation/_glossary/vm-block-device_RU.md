description: Диск или образ, подключённый к виртуальной машине. Образы подключаются только для чтения или как CD-ROM для ISO-образов, диски подключаются для чтения и записи.
lang: ru

Устройства подключаются двумя способами. Список `blockDeviceRefs` в спецификации [виртуальной машины](glossary.html#virtual-machine) задаёт порядок загрузки по позиции или полем `bootOrder` и используется при ручной настройке, например для ISO при установке ОС. [VirtualMachineBlockDeviceAttachment](/modules/virtualization/cr.html#virtualmachineblockdeviceattachment) подключает [диск](glossary.html#vm-disk) отдельным ресурсом, который не участвует в порядке загрузки, через шину `virtio-scsi`, и используется для автоматизации и когда у пользователя нет прав на редактирование машины.

При включённой паравиртуализации оба способа подключают и отключают диски у работающей машины без перезагрузки, если хранилище доступно на узле, где она выполняется. Пока [живая миграция](glossary.html#live-migration) готовит целевой узел, устройства нельзя ни подключить, ни отключить.

Подробнее в разделе [«Подключение дисков и образов к виртуальной машине»](user/virtualization/vm-block-devices.html).
