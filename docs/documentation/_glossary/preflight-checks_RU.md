---
title: Preflight-проверки
description: Проверки, которые установщик выполняет перед установкой Deckhouse Platform.
lang: ru
---

Проверки делятся на общие, проверки для статических кластеров и проверки для облачных кластеров. Отдельная проверка пропускается флагом `--preflight-skip-check` с её именем, `--preflight-skip-all-checks` пропускает все, а команда `dhctl preflight list` выводит полный список. Подсети кластера и шаблон DNS-имён проверяются при загрузке [файла конфигурации установки](glossary.html#installation-config), и эти проверки пропустить нельзя.

Подробнее в разделе [«Установка платформы»](installing/).
