---
title: System namespace
description: A namespace in which the system runs, that is, modules and system components. Running the workload in system namespaces is prohibited.
lang: en
---

System namespaces of Deckhouse Platform have the prefixes `d8-` and `kube-`. The [system](glossary.html#system), its [modules](glossary.html#module) and [system components](glossary.html#system-component) run there.
