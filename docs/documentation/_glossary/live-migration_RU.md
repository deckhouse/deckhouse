---
title: Живая миграция
description: Перемещение работающей виртуальной машины с одного узла на другой без её выключения.
lang: ru
---

Живая миграция используется при балансировке нагрузки, при освобождении узла для [обслуживания](glossary.html#maintenance-mode) или обновления и при обновлении прошивки виртуальной машины, которое иначе потребовало бы перезапуска. Узел передаёт память только одной виртуальной машины за раз и принимает только одну входящую миграцию, а скорость передачи одной миграции ограничена 640 МиБ/с. [Перебалансировка ВМ](glossary.html#vm-rebalancing) также переносит машины живой миграцией.

Подробнее в разделе [«Обслуживание узлов с виртуальными машинами»](admin/configuration/platform-scaling/node/vm-node-maintenance.html).
