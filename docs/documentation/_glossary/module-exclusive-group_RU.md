---
title: Эксклюзивная группа модулей
description: Группа модулей с одним и тем же значением параметра exclusiveGroup в module.yaml. В кластере одновременно может быть активен только один модуль группы.
lang: ru
---

Эксклюзивные группы предотвращают конфликты между [модулями](glossary.html#module), которые выполняют схожие или несовместимые задачи. Включить второй модуль той же группы нельзя, пока активен первый.

Подробнее в разделе [«Структура модуля»](architecture/module-development/structure/).
