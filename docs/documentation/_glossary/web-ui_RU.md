lang: ru
---

Большинство операций, доступных из командной строки через [Deckhouse CLI](glossary.html#deckhouse-cli) или `kubectl`, можно выполнить и в веб-интерфейсе. Он открывается по адресу `console.<CLUSTER_NAME_TEMPLATE>`, где шаблон соответствует [шаблону DNS-имён](glossary.html#public-domain-template) кластера, и содержит разделы Deckhouse, управление узлами, мультитенантность, доступ, сеть, хранилище, безопасность, мониторинг и логирование.

Подробнее в разделе [«Веб-интерфейс Deckhouse Platform»](user/web/ui.html).
