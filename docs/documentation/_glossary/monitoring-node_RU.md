---
title: Узел мониторинга
description: Выделенный узел для Grafana, Prometheus и других компонентов мониторинга. Без таких узлов компоненты мониторинга работают на системных узлах.
lang: ru
---

Выделенные узлы мониторинга рекомендуются в нагруженных кластерах с множеством [алертов](glossary.html#alert) и большими объёмами метрик. Им нужны быстрые диски, не менее 400 IOPS. Узлы мониторинга обычно образуют [группу узлов](glossary.html#node-group) `monitoring`.

Подробнее в разделе [«Рекомендации по настройке узлов кластера»](admin/configuration/high-reliability-and-availability/recommendations.html).
