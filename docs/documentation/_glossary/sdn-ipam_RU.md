IPAM включается на уровне сети через ссылку на пул адресов в Network или [ClusterNetwork](/modules/sdn/cr.html#clusternetwork). Адреса для [кластерных сетей](glossary.html#cluster-network) выделяет администратор кластера из пулов в масштабе кластера. В [сетях проекта](glossary.html#project-network) пользователи создают собственные пулы и могут запросить для интерфейса конкретный адрес. Если к одному поду подключено несколько сетей с IPAM, объекты адресов для каждого интерфейса указывают явно.

Если для [основной сети кластера](glossary.html#main-network) настроен пул, адресами [виртуальных машин](glossary.html#virtual-machine) в этой сети управляет общий IPAM: адрес запрашивается автоматически, а существующие машины переходят на него без смены адресов и без перезапуска.

Подробнее в разделе [«Дополнительные сети для использования в прикладных подах»](user/network/sdn/dedicated.html).
