Deckhouse Platform включает готовые интеграции с распределённым хранилищем Ceph, системами хранения HPE, Huawei и TATLIN.UNIFIED (Yadro), NFS, объектным хранилищем S3 и хранилищами на основе протокола SCSI. Каждая интеграция — модуль с [CSI-драйвером](glossary.html#csi-driver). Вторая группа типов хранилищ — [программно-определяемые хранилища](glossary.html#sds) на дисках узлов кластера.

Подробнее в разделе [«Хранилища»](admin/configuration/storage/).
