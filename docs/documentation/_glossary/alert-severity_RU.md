В описании каждого [алерта](glossary.html#alert) есть параметр Severity со значением от `S1` до `S9`:

- `S1` — максимальный уровень, критический сбой, требуются незамедлительные действия;
- `S2` — высокий уровень, близкий к максимальному, возможная авария, необходимо быстрое реагирование;
- `S3` — средний уровень, потенциально серьёзная проблема, необходима проверка;
- `S4`–`S9` — низкий уровень, проблема есть, но в целом работоспособность не нарушена.

Критичность каждого алерта указана в [списке алертов](reference/alerts.html).
