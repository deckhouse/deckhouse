---
title: Артефакты модуля
description: Три вида артефактов, которые сборка модуля загружает в хранилище образов контейнеров, — образы контейнеров приложений, образ модуля и релиз. Deckhouse Platform загружает и обновляет модуль из них.
lang: ru
---

Образы контейнеров приложений тегируются content-based тегами и указываются в шаблонах. Образ модуля собирается по `werf.yaml` и тегируется семантической версией. Релиз — артефакт версии модуля: у него есть тег семантической версии и тег [канала обновлений](glossary.html#release-channel), по его данным Deckhouse Platform решает, обновлять ли модуль в кластере. Хранилище с артефактами служит [источником модулей](glossary.html#module-source).

Подробнее в разделе [«Сборка и публикация»](architecture/module-development/build/).
