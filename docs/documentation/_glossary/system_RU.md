lang: ru
---

Система состоит из [подсистем](glossary.html#subsystem), которые в свою очередь состоят из [модулей](glossary.html#module) и [системных компонентов](glossary.html#system-component).

Система работает преимущественно в [системных неймспейсах](glossary.html#system-namespace). Части системы, которые обслуживают нагрузку конкретного проекта, могут работать в [пользовательских неймспейсах](glossary.html#user-namespace).
