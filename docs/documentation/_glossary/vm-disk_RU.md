Диск описывает [VirtualDisk](/modules/virtualization/cr.html#virtualdisk). Без источника данных создаётся пустой диск заданного размера. При заданном источнике Deckhouse Platform берёт размер из источника и подбирает по нему класс хранения. Поведение диска зависит от хранилища за StorageClass: на томах файловой системы диск создаётся в формате `qcow2`, на блочных устройствах данные пишутся напрямую, а режим привязки тома определяет, создаётся диск сразу или только после подключения к [виртуальной машине](glossary.html#virtual-machine).

У готового диска можно менять только размер и класс хранения. К машине диск подключается для чтения и записи как [блочное устройство](glossary.html#vm-block-device). Его данные можно зафиксировать в [снимке](glossary.html#vm-snapshot) или выгрузить в файл [экспортом данных диска](glossary.html#vm-disk-export).

Подробнее в разделе [«Диски виртуальных машин»](user/virtualization/disks.html).
