Патч-версия — один из двух видов [релиза Deckhouse Platform](glossary.html#dp-release), второй вид — [минорная версия](glossary.html#minor-version). В [режиме обновления](glossary.html#update-mode) `AutoPatch` автоматически устанавливаются только патч-версии. Начиная с Deckhouse Platform 1.70 они применяются с учётом [окон обновлений](glossary.html#update-window).

Подробнее в разделе [«Обновление»](architecture/updating.html).
