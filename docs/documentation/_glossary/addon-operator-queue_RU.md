[Контроллер Deckhouse](glossary.html#deckhouse-controller) создаёт три вида очередей:

- очередь `main`, которая выполняет глобальные хуки при старте, устанавливает [критичные модули](glossary.html#critical-module), настраивает и удаляет модули;
- несколько параллельных очередей `parallel_queue_0..N` для запуска модулей с учётом [зависимостей](glossary.html#module-dependencies);
- очереди хуков, имена которых заданы в конфигурации [хука](glossary.html#module-hook).

Задача, завершившаяся ошибкой без `allowFailure`, блокирует свою очередь, повтор идёт с экспоненциальной задержкой начиная с 5 секунд. Очереди не блокируют друг друга. Посмотреть очереди можно командой `d8 system queue list`.

Подробнее в разделе [«Механизм очередей»](architecture/deckhouse/queues.html).
