---

Лицензионный ключ нужен, чтобы получать образы коммерческих [редакций](glossary.html#edition) из `registry.deckhouse.ru`, например при обновлении кластера в [закрытом окружении](glossary.html#private-environment) командой `d8 mirror pull`.

Подробнее в разделе [«Обновление DP в закрытом окружении»](guides/airgapped-update.html).
