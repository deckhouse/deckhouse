---
title: System
description: The part of the cluster that keeps it operational, manages resources and automates processes.
lang: en
---

The system consists of [subsystems](glossary.html#subsystem), which in turn consist of [modules](glossary.html#module) and [system components](glossary.html#system-component).

The system runs mostly in [system namespaces](glossary.html#system-namespace). The parts of the system that serve the workload of a specific project can run in [user namespaces](glossary.html#user-namespace).
