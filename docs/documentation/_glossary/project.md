---
title: Project
description: A mechanism for isolating and managing workloads in Deckhouse Platform. A project logically divides the cluster and gives a team its own area to deploy applications, configure resources and manage access within the granted rights.
lang: en
---

Projects provide isolation, support creation from templates, control which platform capabilities are available to the team and are compatible with Kubernetes [namespaces](glossary.html#namespace). A project includes the [main project namespace](glossary.html#main-project-namespace) and may include [additional project namespaces](glossary.html#additional-project-namespace).

For details, see [Multitenancy](admin/multitenancy.html).
