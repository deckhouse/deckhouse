---
title: Stronghold secrets engine
description: A component of the Deckhouse Stronghold secrets store that holds and serves secrets of one kind, for example key-value secrets (KV) or certificates (PKI).
lang: en
---

Secrets engines are managed in the Stronghold web interface: each engine shows its list of secrets (roles, keys and others), its configuration and a button to add a new secret. The web interface is provided by the [`stronghold`](/modules/stronghold/) module and opens at `stronghold.<CLUSTER_NAME_TEMPLATE>`.

For details, see [Secret management web interface](user/web/stronghold.html).
