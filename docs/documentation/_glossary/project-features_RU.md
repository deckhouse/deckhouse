Возможности проекта не являются частью [ролевой модели](glossary.html#rbac). Примеры возможностей: Kubernetes, Virtualization. Возможности отдельного неймспейса внутри проекта ограничиваются [возможностями неймспейса проекта](glossary.html#project-namespace-features).
