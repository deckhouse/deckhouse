Deckhouse Platform supports the following virtualization systems:

* [built-in virtualization](./dvp/overview.html);
* [VMware Cloud Director](./vcd/overview.html);
* [VMware vSphere](./vsphere/overview.html);
* [zVirt](./zvirt/overview.html).

The following sections describe how you can configure integration with each of these virtualization systems.
