Deckhouse Platform интегрируется с инфраструктурой zVirt и создаёт виртуальные машины для узлов кластера по описаниям в ресурсе [ZvirtInstanceClass](/modules/cloud-provider-zvirt/cr.html#zvirtinstanceclass).

## Основные возможности

Интеграция с zVirt предоставляет следующие возможности:

- создание и удаление виртуальных машин в zVirt при создании и масштабировании групп узлов (NodeGroup);
- клонирование виртуальных машин из заранее подготовленного шаблона на основе cloud-образа с `cloud-init`;
- автоматическое создание сетевого интерфейса виртуальной машины на основе профиля vNIC;
- получение сетевых настроек узлов по DHCP или [статическая настройка сети](layout.html#статическая-настройка-сети-узлов) для узлов CloudPermanent-групп;
- заказ томов через CSI-драйвер и [StorageClass для доменов хранения zVirt](storage.html#storageclass-для-доменов-хранения);
- удаление из кластера узлов, виртуальных машин которых больше нет в zVirt.
