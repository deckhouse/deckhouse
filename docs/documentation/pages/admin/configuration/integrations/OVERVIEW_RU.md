Deckhouse Platform предоставляет встроенные средства для интеграции с [облачными провайдерами](../../glossary.html#cloud-provider) и системами виртуализации. Для каждого поддерживаемого провайдера платформа:

- заказывает виртуальные машины и подключает их к кластеру как узлы, в том числе при автоматическом масштабировании [группы узлов](/modules/node-manager/cr.html#nodegroup);
- заказывает диски через CSI-драйвер провайдера, чтобы в кластере можно было заказывать PersistentVolume;
- поддерживает метаданные узлов в актуальном состоянии и удаляет из кластера узлы, которых больше нет у провайдера;
- включает CNI в новых кластерах, по умолчанию [`cni-cilium`](/modules/cni-cilium/).

Часть провайдеров дополнительно создаёт базовую инфраструктуру кластера и балансировщики нагрузки для объектов Service с типом `LoadBalancer`. Возможности каждого провайдера перечислены в обзоре интеграции с ним.

[Развёртывание кластера](../../installing/) проходит одинаково во всех облаках. Различаются только подготовка облака, например создание сервисного аккаунта, и содержимое конфигурационных файлов.

Поддерживаемые [облачные провайдеры](./public/overview.html):

- Yandex Cloud;
- VK Cloud;
- Selectel Cloud;
- OVH Cloud;
- OpenStack;
- Amazon Web Services (AWS);
- Microsoft Azure;
- Google Cloud Platform (GCP).

Возможна интеграция с [частными облаками](./private/overview.html), развёрнутыми с использованием следующих решений:

- VK Cloud;
- OpenStack;
- Huawei Cloud;
- Basis Dynamix.

Помимо облачных провайдеров поддерживается интеграция со следующими [системами виртуализации](./virtualization/overview.html):

- Встроенная виртуализация;
- VMware Cloud Director;
- VMware vSphere;
- zVirt.

Также предусмотрена возможность настроить [гибридные кластеры](./hybrid/overview.html).
