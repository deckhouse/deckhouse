[Marketplace](../../glossary.html#marketplace) — это система управления [пакетами](../../glossary.html#marketplace-package) (packages) в Deckhouse Platform (DP). Пакеты могут быть двух типов:

- **Application** — пользовательская нагрузка, развёртываемая в неймспейсе;
- **Module** — расширение возможностей кластера.

В настоящее время поддерживаются только пакеты Application. Поддержка пакетов Module запланирована в следующих версиях DP.

{% alert level="info" %}
Marketplace доступен в DP, начиная с версии 1.76.
{% endalert %}

Подключение репозиториев пакетов и управление их сканированием описаны [в разделе «Администрирование»](../../admin/configuration/marketplace/).

Установка и удаление приложений из Marketplace, а также диагностика проблем описаны [в разделе «Использование»](../../user/marketplace/).

## Разделы

Документация Marketplace представлена в следующих разделах:

- в разделе [«Концепции»](concepts.html) описаны типы пакетов, модель ресурсов, ограничения Application и этапы установки приложения из пакета;

- в разделе [«Разработка приложений»](application-development.html) описано создание пакета Application с нуля: бутстрап, структура проекта, `package.yaml`, локальный рендеринг и проверка, сборка, CI/CD и артефакты пакета в хранилище образов;

- в разделе [«Настройки приложения»](settings.html) описаны OpenAPI-схемы настроек и values: валидация, значения по умолчанию и расширения, управляющие формой настроек в веб-интерфейсе;

- в разделе [«Шаблоны»](templates.html) описаны значения, доступные шаблонам Application, именование объектов, образы контейнеров, Ingress и [адреса приложения](../../glossary.html#application-endpoints);

- в разделе [«Аннотации Nelm»](nelm-annotations.html) описан полный набор аннотаций Nelm, которые используются в шаблонах Application для управления порядком развёртывания, жизненным циклом ресурсов, отслеживанием готовности и выводом логов;

- в разделе [«Хуки»](hooks.html) описано, как писать Go-хуки для приложений с помощью типа `ApplicationHookInput` из module-sdk;

- в разделе [«Жизненный цикл и отладка»](lifecycle.html) описано, как DP устанавливает, обновляет и удаляет Application, и какие инструменты помогают отлаживать пакет.
