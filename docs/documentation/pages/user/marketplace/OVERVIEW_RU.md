[Marketplace](../../glossary.html#marketplace) позволяет устанавливать готовые приложения в свой неймспейс из репозиториев, подключённых администратором кластера. Каждое приложение устанавливается в виде ресурса [Application](../../reference/api/cr.html#application) и может существовать в нескольких независимых экземплярах, например, отдельные экземпляры Redis для кеширования и для сессий в одном неймспейсе.

{% alert level="info" %}
Marketplace и ресурс Application доступны в Deckhouse Platform, начиная с версии 1.76.
{% endalert %}

Подключение репозиториев [пакетов](../../glossary.html#marketplace-package) и управление их сканированием описаны [в разделе «Администрирование»](../../admin/configuration/marketplace/).

Архитектура Marketplace, включая основные концепции, разработку и настройку приложений, шаблоны, аннотации Nelm, хуки и жизненный цикл приложений, описана [в разделе «Архитектура»](../../architecture/marketplace/).

## Предварительные условия

Перед установкой приложения администратор кластера должен подключить хотя бы один репозиторий пакетов. Проверьте, что объекты [ApplicationPackageVersion](../../reference/api/cr.html#applicationpackageversion) доступны:

```bash
d8 k get apv
```

Если вывод пуст, репозиторий ещё не сканировался или в нём нет пакетов. Если команда завершается ошибкой `Forbidden`, у вас нет прав на просмотр версий пакетов. В обоих случаях обратитесь к администратору.

В разделе [«Установка и управление приложениями»](applications.html) описан порядок просмотра доступных версий, установка, обновление и удаление приложений.

В разделе [«Диагностика»](troubleshooting.html) описано, как диагностировать и устранять проблемы с установленными приложениями.
